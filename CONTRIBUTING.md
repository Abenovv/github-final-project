# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

Please follow `CODE_OF_CONDUCT.md`. For a bug report, describe the inputs, expected result, observed result, and environment without sharing sensitive information. For a proposed change, explain its purpose and include a small example demonstrating the behavior.

Keep changes focused, preserve the original author's attribution, and document relevant changes to the sample. Contributions should be compatible with this project's Apache License 2.0.
